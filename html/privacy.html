1. Overview

Classroom Checker is a desktop application for teachers. It helps teachers review Google Classroom assignments and identify student submissions that have not been graded yet.

2. Google user data accessed

With the user's permission, Classroom Checker may access Google Classroom data such as:

  • Classroom courses/classes
  • Coursework created in Google Classroom
  • Student submissions and grading status
  • Student names or profile information needed to identify submissions

3. How Google user data is used

Google Classroom data is used only to show the signed-in teacher a list of ungraded student submissions, including student name, class name, assignment/coursework information, and grading status.

4. Data storage

Classroom Checker stores OAuth authentication tokens locally on the user's computer so the user does not need to sign in every time the app is opened.

Classroom Checker does not operate a public server database for storing Google Classroom content.

5. Data sharing

Classroom Checker does not sell Google user data.

Classroom Checker does not share Google user data with third parties.

Classroom Checker does not use Google user data for advertising.

6. Data protection

OAuth tokens are stored locally on the user's device. Users should protect their device account with a password or operating system login protection.

7. User control and revocation

Users can stop using the app at any time. Users can also revoke the app's access from their Google Account permissions page:

https://myaccount.google.com/permissions

8. Data deletion

To remove local app data, users can sign out from the app or delete the app's local storage files from their computer. Users may also contact support for deletion instructions.
